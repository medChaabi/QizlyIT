# 🚀 Qizly

Bienvenue dans le dépôt communautaire officiel de **Qizly** ! Cet espace est dédié au partage de ressources pour l’application Qizly, disponible sur [qizlyapp.com](https://qizlyapp.com).

Ce dépôt permet aux utilisateurs de la communauté de collaborer, de partager des quiz (fichiers JSON) et des documents de référence (PDF) pour s’entraider dans leur apprentissage.
